# Сайт Pulsar VPN

Готовая первая версия сайта на **Python + Flask + Jinja2** с самостоятельными CSS и JavaScript. Дизайн использует тёмно-синий цвет логотипа, реальные скриншоты клиента и анимации без стороннего JavaScript-фреймворка.

## Контакты

Публичные контакты взяты из README приложения:

- Telegram: https://t.me/ggoktay
- Ошибки и предложения: https://github.com/oktaygg/Pulsar-VPN-Client/issues
- Разработчик: https://github.com/oktaygg

Меняйте их в `site_config.json`.

## Анимации и взаимодействия

- Звёздное поле, светящиеся орбиты и мягкая пульсация.
- Лёгкий наклон скриншота вслед за курсором на компьютерах.
- Появление разделов при прокрутке и индикатор чтения.
- Закреплённый обзор: прокрутка последовательно показывает серверы, приложения, сайты, стандартную и чёрно-белую темы. Затем продолжается обычная прокрутка страницы.
- Четыре отдельных исходных скриншота белых списков и тем оформлены парами окон с глубиной и сменой переднего плана.
- Три вкладки и кнопки выбора отдельных экранов; доступны стрелки клавиатуры, Home и End.
- Плавные реакции кнопок и анимация концепта телефона.
- Раскрывающиеся ответы и мобильное меню с закрытием по Escape.
- Учитывается системная настройка уменьшения движения. Отдельной кнопки паузы на сайте нет.

Звёзды останавливаются, когда первый экран не виден или вкладка скрыта. Основной текст и скачивание доступны без JavaScript.

Закрепление включается при достаточной высоте экрана: на компьютере от 900 × 640 px, на меньших экранах от 360 px по ширине и 740 px по высоте. На компактных экранах и при уменьшении движения обзор работает как обычный блок с вкладками. Прокрутка остаётся нативной: обработчиков блокировки колеса или жестов нет.

## Публикация

Python-версию можно запускать через Waitress за HTTPS reverse proxy:

```powershell
waitress-serve --host=127.0.0.1 --port=8000 app:app
```

Для хостинга без Python экспортируйте ту же страницу:

```powershell
python build_static.py
```

## Содержательные границы

Pulsar — бесплатный клиент. Подписка или свой сервер нужны отдельно. На сайте нет вымышленных отзывов, статистики скорости или гарантий обхода ограничений. Мобильный экран явно помечен как концепт в разработке; дата выпуска и платформы не обещаются.
